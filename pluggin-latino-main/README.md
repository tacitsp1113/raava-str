# Tacit-str Plugin

Plugin para Nuvio y Stremio. Contenido en Español/Latino: películas, series, anime y doramas de distintos proveedores web.

[![JavaScript](https://img.shields.io/badge/JavaScript-Runtime-black?style=for-the-badge&logo=javascript&logoColor=white&color=F7DF1E)](https://developer.mozilla.org/docs/Web/JavaScript)

## Características

- 54 proveedores de contenido latino y anime.
- Extracción de enlaces directos HLS (.m3u8) y MP4.
- Compatibilidad directa con reproductores externos y TV.
- Sin dependencias de servidores externos privados ni rastreadores.
