# 🗡️ TACIT STR

> *Inspirado en el legendario Jaeger Mark-1 "Tacit Ronin" (Titanes del Pacífico). Diseñado para máxima velocidad, precisión quirúrgica y potencia en streaming latino.*

Addon híbrido para **Stremio** con soporte para películas, series y anime en **Español Latino**. Combina lo mejor de dos mundos:
- ⚡ **Streaming Directo Instantáneo:** Servidores de alta velocidad (Vimeos, VOE) con reproducción inmediata sin descargas ni espera de seeders.
- 🧲 **Torrents P2P de Alta Fidelidad:** Enlaces 4K HDR y 1080p Full HD con verificación de semillas activas en tiempo real.
- 🎛️ **Página de Configuración Interactiva (`/configure`):** Personalización total de proveedores, calidades deseadas, límite de enlaces y orden de prioridad.

---

## 🚀 Despliegue e Instalación

### 1. Ejecución Local
```bash
npm install
npm start
```
Abre tu navegador en:
👉 **`http://localhost:7000/configure`**

### 2. Despliegue en Render
El proyecto incluye [render.yaml](file:///c:/Users/jesua/Downloads/raava-str/render.yaml) configurado para desplegarse automáticamente como Web Service en Node.js.
